# 赛博朋克RED工具箱 — Owlbear Rodeo 扩展 + 写卡向导

Owlbear Rodeo（枭熊）的赛博朋克RED（CPR）规则扩展插件 + 鲨鱼包写卡引导网页。
规则口径：**CPR本体 + 鲨鱼包（RED体验改良整合包）**，鲨鱼包数值优先，全部数据驱动（规则数据包 + registerRuleset），后续可加新数据包扩展。

- 写卡向导：`https://apocrypha5662.github.io/owlbear-cyberpunk-red/creator/`

## 一、插件安装（枭熊房间内）— 多按钮分体版（v1.1.0）

自 v1.1.0 起，功能拆分为 **6 个独立扩展按钮**（参考常见枭熊套件的分按钮布局），每个按钮打开聚焦面板；角色数据/设置/金钱存同一来源（localStorage + 房间 metadata），任意按钮间互通。**按需安装，不必全装**：

| 按钮 | Manifest URL | 功能 |
|------|--------------|------|
| 🎲 CPR骰盘 | `https://apocrypha5662.github.io/owlbear-cyberpunk-red/manifest.json` | 快速检定/自定义掷骰（含右键菜单注册） |
| ⚔️ CPR战斗 | `https://apocrypha5662.github.io/owlbear-cyberpunk-red/manifest-combat.json` | 射程DV/点射扫射/部位/削甲/重伤/死亡豁免 + 令牌HP伤势 |
| ⏱ CPR先攻 | `https://apocrypha5662.github.io/owlbear-cyberpunk-red/manifest-init.json` | 先攻面板（1d10+REF，排序/下一轮） |
| ¥ CPR金钱 | `https://apocrypha5662.github.io/owlbear-cyberpunk-red/manifest-money.json` | 私密金钱/黑入查账 |
| ⬇ CPR导入 | `https://apocrypha5662.github.io/owlbear-cyberpunk-red/manifest-import.json` | JSON/xlsx 角色导入 + 规则包开关 |
| 📖 CPR速查 | `https://apocrypha5662.github.io/owlbear-cyberpunk-red/manifest-quickref.json` | 鲨包射表/甲弹对抗/重伤表/三色反应/ACPA |

安装步骤（每个按钮一次）：

1. 打开枭熊个人主页 → **Add Extension**（或扩展管理「+」Add custom extension）；
2. 粘贴上表中的 manifest URL → 出现卡片后点 **Add**；
3. 进房间，左下 **"…" 菜单 → Extensions** 勾选启用；
4. 启用后左上工具栏出现对应图标按钮；
5. 画布中**右键令牌** → 「CPR状态」/「CPR先攻」（右键菜单由「CPR骰盘」扩展注册，装了骰盘即可用）。

> 旧版单按钮「赛博朋克RED工具箱」已由 `manifest.json`（现为 CPR骰盘）替代；若此前装过旧版，建议在 Profile 中删除旧扩展后重新添加，以免两个同名入口混淆。

## 三、私密金钱（重点）

- 余额与流水**只存玩家本机 localStorage**（按玩家ID键控），**绝不写入**房间/场景 metadata，**绝不走** broadcast 信道——其他玩家的插件实例读不到；
- 「黑入查账」：发起方掷 1d10+技术+电子/安全技术，目标端自动掷 1d10+技能/2 对抗；
  - 发起方失败 → 目标端收到「有人试图黑入你的账户」警告；
  - 发起方成功 → 目标端回传余额，**该数字只在发起方界面渲染**；
- GM 视角：设置里可开「GM 视角」，只显示**玩家主动点「向GM上报余额」**的数据（默认关）；
- **如实声明**：枭熊 broadcast 是全房间信道，技术上**不存在端到端私密传输**。本方案是「本机存储 + 界面级可见性控制」的务实实现——拿到回传消息的中间人（例如手改插件代码的人）理论上可见，正常玩家界面不可见。

## 四、写卡向导（/creator/）

分步向导：① 基本信息 → ② 属性（62点/2~8/9d10随机，共情×10=人性）→ ③ 职业（主职业+兼职，主职业≥4可兼职）→ ④ 技能（86点，[x2]技能折半）→ ⑤ 义体（自动扣人性，期望值口径）→ ⑥ 武器/护甲（预设+自定义）→ ⑦ 资金。
导出：**填好的鲨鱼包全自动卡 xlsx**（SheetJS 直接写模板输入格，公式保留，打开后 WPS/Excel 自动重算）+ **角色数据 JSON**（供插件导入，含金钱初始值）。

## 五、数值来源与调整说明（硬规则）

所有数值条目带 `source` 字段：
- `shark` = 鲨鱼包（鲨包速查V1.91 / 人物卡公式）第一优先；
- `core` = CPR官方本体（本地整理的战斗速查/杂项表）；
- `ext` = 第三方扩展原文（三色反应动作体系 v0.7 PDF）；
- `inferred` = 推演值（附 reason 真实参照 + errata 原版不合理说明）。

## 六、待用户确认清单（无人值守自行决策项）

1. **火箭筒伤害 8d6**：两份本地表冲突（6d6 vs 8d6），取杂项表8d6。
2. **全自动DV**：鲨包速查只有全自动射表（按弹数? 按距离），本插件按「鲨包全自动射表定DV + 每多发1发+2DV + 命中数=floor((结果-DV)/2)」组合，弹数上限取「全自动弹幕4x8」的第一个数字（4发）。「x8」按散布半径解释为纯展示——请核对鲨包整合包原文。
3. **死亡豁免判读**：≥10 判死（惩罚加算）。请按你习惯的官方口径复核。
4. **技能点/属性点默认值**：86/62（官方边缘行者法口径），车卡指南要求问 RF，向导中均可改。
5. **三色反应**：按 v0.7 PDF 原文实现为蓝/绿/红反；默认关闭，价格用原文「测试用估值」。
6. **金钱初始值口径**：xlsx 导入 = 购物助手「初始资金J54」+「流动/赞助J53」+ 往来记录 M/N 收支合计。
7. **GM身份**：枭熊 API 无稳定 GM 判定，采用手动开关。
8. **参考房间未进入**：房间 56wNR9-Jg-NP/AdiosCowboy 自动化阶段未能进入实测（无人值守不能弹批准窗口），UX 参考改用枭熊官方扩展教程（initiative-tracker）与公开扩展生态交互惯例。
9. **UX翻译**：所有界面文案中文；机翻规则原文（专注/忍耐等技能名、重伤表效果文本）已按语义润色。
10. **写卡向导技能表**：只列了鲨包人物卡常用技能（乐器子项、武术子项、科学子学科等未展开），下载后可在 xlsx 中手工补充。

### 运行依赖说明（v1.2.0）

- 所有插件功能（骰盘/战斗/先攻/金钱/导入/速查/右键菜单）**全部在枭熊房间内运行**，不依赖枭熊以外的任何服务或网页；
- 面板 HTML 必须托管在公网（枭熊扩展机制决定），当前托管于 GitHub Pages，`app.js` 加载失败时自动切换 jsDelivr 镜像；
- 唯一按需加载的外部资源：SheetJS 解析库（约 900KB），**只在玩家上传鲨鱼包 xlsx 导入角色那一刻才加载**，JSON 导入、掷骰、战斗等一切功能均不需要它；
- 写卡向导（/creator/）是独立工具网页，可选使用——不访问它也能在房间内用「CPR导入」按钮完成 JSON/xlsx 导入；
- 速查面板为房间内数据，如需翻规则书原文可自行开外部页面查阅（不依赖）。

### 国内网络加速（github.io 不稳定时）

- 刷新房间页面（F5）后再点插件按钮，多数情况可恢复。
- 仍失败时可改用 jsDelivr 镜像 manifest 安装（内容与 GitHub 同步）：
  `https://cdn.jsdelivr.net/gh/Apocrypha5662/owlbear-cyberpunk-red@main/manifest.json`
  （在枭熊 Profile 里删掉旧扩展再添加此链接；jsDelivr 有约 12 小时缓存，更新后有延迟。）
- 写卡向导页同样可走镜像：`https://cdn.jsdelivr.net/gh/Apocrypha5662/owlbear-cyberpunk-red@main/creator/`
